# 📚 AI Document Assistant (RAG App)

A Retrieval-Augmented Generation (RAG) application that lets you upload a document (PDF, TXT, or DOCX) and ask questions about its contents. Answers are generated by Mistral AI's language models, grounded strictly in the text retrieved from your document — the app will tell you when it can't find an answer instead of guessing.

## Features

- 📤 Upload PDF, TXT, or DOCX files through a simple Streamlit interface
- ✂️ Automatic text extraction and chunking for optimal retrieval
- 🧠 Embeddings generated with Mistral AI (`mistral-embed`) and stored in **ChromaDB**
- 💬 Chat-style question answering grounded in the uploaded document
- 🚫 Refuses to hallucinate — explicitly says when an answer isn't in the document
- 📄 Shows the source chunks used to generate each answer
- 🔄 Upload a new document at any time to replace the current knowledge base
- 🗑️ One-click conversation reset
- 💾 Persistent ChromaDB storage between runs

## Installation

1. **Clone or copy the project files** into a folder, then navigate into it:

   ```bash
   cd rag_app
   ```

2. **Create a virtual environment** (recommended):

   ```bash
   python -m venv venv
   source venv/bin/activate   # On Windows: venv\Scripts\activate
   ```

3. **Install dependencies:**

   ```bash
   pip install -r requirements.txt
   ```

## Environment Variable Setup

1. Get a free Mistral API key at [console.mistral.ai](https://console.mistral.ai/).
2. Copy the example env file:

   ```bash
   cp .env.example .env
   ```

3. Open `.env` and set your key:

   ```env
   MISTRAL_API_KEY=your_api_key_here
   ```

   Optional overrides are also available in `.env`:

   ```env
   MISTRAL_CHAT_MODEL=mistral-small-latest
   MISTRAL_EMBED_MODEL=mistral-embed
   CHROMA_PERSIST_DIR=./chroma_db
   ```

   Check [Mistral's model list](https://docs.mistral.ai/getting-started/models/) for the latest available free/low-cost models if `mistral-small-latest` isn't accessible on your account.

   **Never commit your `.env` file** — it's already excluded via `.gitignore`.

## Running the Application

```bash
streamlit run app.py
```

Streamlit will open the app in your browser (typically at `http://localhost:8501`).

### Using the app

1. Upload a PDF, TXT, or DOCX file.
2. Click **Process Document** — the app will extract text, split it into chunks, generate embeddings, and store them in ChromaDB.
3. Type a question in the input box and click **Ask**.
4. Read the answer, and expand **Sources** to see which chunks were used.
5. Upload a new file at any time to replace the current knowledge base, or use **Clear conversation** to reset the chat history.

## How the RAG Pipeline Works

1. **Loading:** `document_loader.py` detects the file type and uses the matching LangChain loader (`PyPDFLoader`, `TextLoader`, or `Docx2txtLoader`) to extract raw text.
2. **Chunking:** The text is split into overlapping chunks (~1000 characters, 150-character overlap) using `RecursiveCharacterTextSplitter`, preserving enough context per chunk for accurate retrieval.
3. **Embedding & Storage:** `vector_store.py` embeds each chunk with Mistral's `mistral-embed` model and stores the vectors in a persistent ChromaDB collection. Uploading a new document clears the previous collection so the knowledge base always reflects the latest upload.
4. **Retrieval:** When a question is asked, `rag_pipeline.py` performs a similarity search against ChromaDB to find the most relevant chunks (top 4 by default).
5. **Generation:** The retrieved chunks are inserted into a strict system prompt that instructs the Mistral chat model to answer **only** using that context, and to respond with *"I could not find this information in the uploaded document."* if the answer isn't present.
6. **Display:** `app.py` shows the generated answer along with the source chunks (file name, chunk index, and a text preview) so you can verify where the answer came from.

## Error Handling

The app handles common failure cases gracefully with user-facing messages instead of crashing:

- No file uploaded / no question entered
- Unsupported file type
- Empty or unreadable document
- Missing `MISTRAL_API_KEY`
- Mistral API errors (rate limits, invalid key, network issues)
- ChromaDB / vector store errors during embedding or retrieval

## Notes

- Mistral's free tier and rate limits change over time — check the [Mistral pricing page](https://mistral.ai/pricing/) for current details.
- ChromaDB data is persisted to `./chroma_db` by default so your embeddings survive app restarts. Delete that folder to fully reset storage.
